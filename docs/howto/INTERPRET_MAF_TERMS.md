# How to Interpret MAF Terms

Use three documents together:

- `docs/architecture/AUTHORITY_AND_TERMINOLOGY.md` for normative meaning;
- `docs/getting-started/GLOSSARY.md` for plain-language explanation;
- `docs/terminology/COINED_TERMS.md` for coined-term status and lineage.

## Status matters

A historical or compatibility identifier can remain valid
even when it is not the preferred current-facing name.

For example, an existing `openmind.*` schema identifier may
remain authoritative for historical data while new
documentation uses the MAF project identity.

Do not infer that a terminology update authorizes rewriting
old evidence.
