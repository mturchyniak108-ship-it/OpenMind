# MAF How-To Guides

This directory contains task-oriented documentation.

How-to documents answer **how do I do this?**

They are intentionally separate from:

- conceptual explanations;
- normative terminology;
- frozen research protocols;
- API/schema reference material.

## Available guides

- [Read the MAF documentation](READ_THE_MAF_DOCUMENTATION.md)
- [Interpret MAF terms](INTERPRET_MAF_TERMS.md)
- [Trace MAF provenance](TRACE_MAF_PROVENANCE.md)
- [Work with historical OpenMind artifacts](WORK_WITH_HISTORICAL_OPENMIND_ARTIFACTS.md)

## Future task guides

Candidate future guides include:

- inspect a MAF object;
- resolve a PK;
- inspect a segment;
- validate provenance;
- inspect a catalog;
- validate reconstruction;
- run static repository checks;
- build the supported native runtime;
- reproduce an explicitly authorized benchmark.

Execution-oriented guides must preserve the authorization
boundary between reading documentation and executing model
or research workloads.
