# How to Read the MAF Documentation

Start with `docs/index.md`.

## Recommended order

1. Read `docs/concepts/MAF_OVERVIEW.md`.
2. Read `docs/getting-started/GLOSSARY.md`.
3. Use `docs/terminology/COINED_TERMS.md` for project-specific terminology.
4. Read `docs/reference/MAF_OBJECT_MODEL.md` for structural concepts.
5. Read `docs/provenance/OPENMIND_TO_MAF_LINEAGE.md` before interpreting historical OpenMind artifacts.
6. Use `docs/research/PHASE_6_SUMMARY.md` for the bounded Phase-6 result.

## Authority order

When documentation disagrees, prefer the applicable frozen
protocol/evidence and the current authority/terminology
document over an informal overview.

Historical research documents remain evidence of what was
stated at the time; they are not silently rewritten to match
current terminology.
