How to Work with Historical OpenMind Artifacts

OpenMind is the historical repository and research-lineage identity from which MAF emerged.

Do

  • preserve original paths;
  • preserve schemas;
  • preserve Git history;
  • preserve frozen hashes and blobs;
  • distinguish historical failures from active defects;
  • cite the original authority when reproducing a result.

Do not

  • mass-rename historical artifacts;
  • rewrite openmind.* schema identifiers;
  • change frozen Phase-6 evidence to match current branding;
  • treat a current MAF name as proof that historical artifacts originally used that name.

Present-facing documentation

New documentation may explain that an artifact belongs to the OpenMind → MAF lineage without modifying the artifact itself.
