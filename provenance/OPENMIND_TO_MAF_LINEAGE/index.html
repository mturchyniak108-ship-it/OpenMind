OpenMind → MAF Lineage

Historical identity

The repository and its earlier research were developed under the name OpenMind.

That historical identity remains part of the provenance record.

Successor identity

After formal closure of Phase 6, the model-object representation/addressing direction is identified as:

MAF — Model Address Fabric

Preservation policy

The transition is a lineage transition, not a historical rewrite.

Therefore:

  • Git history remains unchanged;
  • historical commit subjects remain unchanged;
  • frozen research paths remain unchanged;
  • frozen result files remain unchanged;
  • openmind.* schemas remain valid historical/compatibility identifiers;
  • original OpenMind attribution remains visible.

Current compatibility state

At the time this document is introduced:

  • the Git repository is still named OpenMind;
  • the active research branch remains unchanged;
  • the Python package still uses openmind;
  • native include/symbol surfaces still contain OpenMind names;
  • no remote rename is implied by the MAF documentation identity.

Those are separate migration/publication decisions.

External OpenMind projects

The existence of unrelated or external projects named OpenMind does not alter this repository's historical record.

Any future collaboration or integration must be evaluated separately from the lineage/rebrand operation.
